# 闭合战役计划 v1（2026-09-18 · 暂停新功能开发期间的诚实声明清账）

> 本计划由主会话在 R89 收官后制定，替代「继续第三梯队（R90 毛发起）」的默认路线。
> 判定门三问：**存在性核实**（代码亲验，声明不滞后）→ **需要闭合**（收益真实，
> 不与裁定/红线冲突）→ **可以闭合**（有明确修法，不触 'static 边界 / 跨适配器
> 定义性边界 / 拒绝清单）。全部核验基于 commit bbd7955。

## 一、§8 全量 58 条分类底账（先止血：哪些根本不是债）

### A. 档案类（摩擦已修复，条目留档，无动作）——10 条
§8.12 / 13 / 15 / 18 / 22(dogfooding V) / 26（六轮 dogfooding 全部「已修复/已闭合」，

### B. 定义性 / 裁定维持类（**不闭合**，闭合=破坏设计意图）——约 30 条
- **类型系统 / 平台定义边界**：§8.1（'static 常驻池，Arc\<World\> 重构判「不抵风险」）、
  §8.5（wasm 离屏恒 None）、§8.39⑤ / 51① / 52⑤ / 57⑩（跨适配器位级不可保 = 定义性）、
  §8.40⑤⑥（Delaunay 抖动真值±1µm）。
- **屏幕空间 / 低频近似定义边界**：§8.38①（SSR 只反射上帧屏幕）、§8.36①（TAA 无逐物体
  运动向量 = 拒绝清单）、§8.52③（L2 截断分辨率上限）、§8.57⑦（chebyshev 概率上界）。
- **艺术化口径裁定**：§8.48④（大气非物理量纲）、§8.49④~⑦（太阳弧单平面/风单八度）、
  §8.39②（Penner 增能取舍）、§8.55①（体素聚类非 QEM 已裁定接受）、§8.58④（贴图互斥
  = 裁定 2 代价）。
- **全案 MVP 红线**：§8.53~56 的无 visbuffer / opaque-only / 无软件光栅 / 磁盘 IO 不做
  （红线修订明示）。
- **作者责任 / 格式自觉代价**：§8.33④（产物引用对加载序敏感）、§8.44（GLB 不产窗口曲线
  = glTF 标准外）、§8.57④（geometry_generation 显式宣告 = 裁定）。
- **其余「留后续轮」但无近期收益的**：§8.2（递归传播栈深，游戏规模足够）、§8.25
  （时间线单播放器，W8 前不动）、§8.34（编辑器 MVP 红线内）、§8.35（注册表网格/纹理
  去重 = 独立工程）、§8.37②（盒面近似 = 探针方法的定义）、§8.41（行为树拒绝清单）、
  §8.46（GTAO 简化 = 成本取舍，无池项）、§8.47①（锥光投影 = 大工程，见 E 类）。

## 三、批次编排建议（串行，每批 = 一轮，门禁同规格）

> 排序原则：①先还「玩家/作者可见」的债，再还「工程账面」的债；②渲染像素重锁面
> 大的合并成役、摊薄归因成本；③设计专章前置的（GJK/OIT/光照口径）先出设计稿再排码；
> ④每批收官照旧六项门禁 + 基线数字更新。

- **C0 · 文档健康轮**（半天，零代码）：修 §8.17 过期注记、22 双编号重排+全文引用修正、
  A 类条目加「档案」标、_FEATURES 数字轮巡。**这批无条件做**——它是本计划可信度的基础。
- **C1 · 原语小件轮**（低风险速胜）：#14 register_component + #15 RT resize + #7 LOD v2
  （滞回+包围球中心，缺席=逐位不变）+ #16 原生数据贴图免 BC1 声明口。四项全小、
  互相独立、各自带兼容形态锚。
- **C2 · 渲染伪影闭合役**（像素重锁役 ①）：#6 贴花 v2 受光 + #17 光照贴图 mip +
  #18 粒子序列化 + #19 探针编辑器入口。归因+重锁程序统一走。
- **C3 · 物理深化役**：#3 CCD（先）→ #1 关节/约束 v2 → #2 OBB+凸包（GJK 确定性
  专章**先行**，专章不过审则 OBB 缓行、CCD+关节 v2 不受阻）。#4 RVO 视裁定挂载。
- **C4 · 动画役**：#8 形变目标 + #9 状态机 v2 + 运行时重定向 + #10 动画压缩（压缩可
  裁出，改期不阻塞）。
- **C5 · 格式役**：#11 BC7+KTX2（编码决策树 + 容器 + 声明门三件套），与 C2 的 #16
  呼应；#12 热重载局部（材质/光照参数子集）。
- **C6 · 音频役**：#13 空间化 v3（遮挡/多普勒/逐声音滤波优先，HRTF 单独裁定）。
- **C7 · 大裁决役**（设计稿先行，用户逐案拍板后才排码）：#5 OIT、#20 光照口径三件套、
  #21 DDGI 动态光源+天空同源。三者共同点：像素基线大面积重锁 + 语义裁定多，
  **必须归因+重锁程序 + 设计稿留档 docs/private/**。

依赖提示：#20（光照口径）会重写环境镜面项与曝光链——若先行，C2/C7 的重锁基线要
跟着二次迁移；**建议 #20 与 #5 同役或 #20 最后**，避免重复重锁。
