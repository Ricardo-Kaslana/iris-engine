## 一、问题与范围

路线图 v5 闭合池明示：「OBB + 凸包（GJK，浮点确定性论证最重，需设计
专章）」。本章程回答三问：

1. GJK/EPA 类通用凸体检测在本仓确定性文化（同输入逐位一致、跨运行
   快照逐字节）下**哪里会破**；
2. 每条风险的**消除手段**是否落在「纯 CPU、零 unsafe、无新依赖」的
   工程边界内；
3. 哪些子集**值得现在开工**（给出拆段建议），哪些应缓行。

不在范围：连续碰撞（已由 C3 `Ccd` 子步法闭合，GJK 不做 sweep 版）、
非凸三角网格整体（凸分解不在红线内展开）、刚体接触摩擦锥（v2 求解器
现状维持）。

## 二、风险清单（逐条：机理 → 现行同类先例 → 消除手段）

### R1 浮点运算集合（跨平台位级）

- **机理**：逐位一致要求每一步运算在所有目标平台上产生同一比特。
  IEEE-754 保证 `+ − × ÷` 与**正确舍入 sqrt** 跨平台一致；超越函数
  （`sin/cos/atan2/pow`）走 libm，实现随平台变，**无位级保证**。
- **现行先例**：`solve_swing_joint` 只用 `dot/cross/sqrt/归一除法 +
  from_rotation_arc`（内部无超越）；`swing_limit` 消费方在**收集期**
  预取 `cos/sin`（一次求值，结果进 f32 快照）——运行期比较全是
  `dot < cos_limit` 型。教训条目：AGENTS「sqrt 优于 hypot」。
- **手段（GJK 适配）**：GJK 内核允许算子集合 = `{dot, cross, sub, neg,
  比较, sqrt, 除法}`——**足够，无需任何超越函数**（法线由叉积导出、
  距离由长度平方比较、最近点由重心组合，全程可避开归一化：比较用
  长度**平方**，只在最终输出法线时除一次）。EPA 同理。
  规定：**内核函数体内禁止出现 `sin/cos/atan2/pow/exp/hypot`**，以源码
  级看门单测锁死（照 `skybox_globals_prefix_matches_standard_layout`
  影子契约模式：对实现源码 regex 断言禁用算子出现——新增看门）。

### R2 表达式收缩（FMA）

- **机理**：`a*b+c` 若被编译为 FMA（单舍入），与两次舍入的 `mul+add`
  逐位不同；同一行代码在不同 target feature（x86-64 基线无 FMA、
  `-C target-cpu=native` 有）下结果漂移。
- **现行先例**：R63 已立口径——热路径数学写成显式分步、不让 LLVM 融合
  （rustc 默认不开 `fast-math`，融合只在启用 fma 指令集的构建里发生；
  本仓发布构建从不加 `target-cpu=native`，AGENTS 门禁全走基线）。
- **手段**：仓内构建矩阵不变（native 调试构建允许本机差异、**门禁与
  dogfooding 快照全在基线 x86-64 / wasm32-unknown-unknown**）；内核
  中点积 / 叉积按「先乘满、后累加」的分步写法，累加次序写进注释视为
  契约。

### R3 迭代终止与比较边界

- **机理**：GJK 主循环条件形如 `if new_dist >= old_dist { 收敛 }`；
  等号在浮点噪声下可翻转 → 两跑分岔（多一轮 / 少一轮）。EPA 的
  「最近面」选择、扩张判据同病。
- **手段**：
  1. **迭代上限写死常数**（`GJK_MAX_ITERATIONS = 32`、
     `EPA_MAX_ITERATIONS = 64`，超限走确定性回退，见 R5）——循环界与
     浮点无关，最坏代价有界；
  2. **所有边界归属显式化**：`>=`/`>` 逐处注释指定（本仓规约「边界
     归近侧」先例 = `LodMesh::select` 的 ≤ 用 high）；
  3. 距离比较一律用**长度平方**（避免 sqrt 噪声参与分支；sqrt 只在
     收敛后出答案时算一次，不进任何分支条件）。

### R4 退化构型（simplex 循环 / 共面 / 反平行）

- **机理**：GJK 已知病理：四点共面、原点恰在单纯形边界、方向向量
  与面法线垂直 ⇒ wolfe 条件选不出新点 → **循环不收敛**（教科书级
  numerical robustness 问题，不是本仓新病）。
- **现行先例**：仓内对退化的统一口径 =「**确定性任意方向 / 跳过**，
  绝不凭空随机」：`sphere_sphere` 重合取 +Y、锥面退化取
  `any_orthonormal_vector()`（glam 该函数按分量分派，确定）、
  `Ccd` 自动段长 0 ⇒ 关闭。
- **手段**：
  1. 原点在单纯形**边界上**（距离 = 0 的判定向）：规定「归内」——
     `dot ≤ 0` 归零侧（等号指定，配合 R3②）；
  2. 循环检测：连续两轮 `same_support(w)`（点积 ≥ 1 − 1e-7 的**常数**
     阈值比较，非自适应）⇒ 视为收敛，走 R5 回退；
  3. **SoS（symbolic perturbation）评估**：本仓文化倾向可用则用——
     GJK 的 SoS 只作用于「选哪侧单纯形」的符号比较（纯整数位比较，
     不引入浮点误差），实现代价中。**结论：v1 不启用 SoS**，理由 =
     上面 1+2 两条已把全部退化推向可判定的确定分支，SoS 的收益要到
     「任意凸包 × 任意姿态」的对抗样本池才显现，而 v1 消费方（OBB、
     盒、胶囊采样点集）构型温和；留作凸包轮的复审项。

### R5 回退路径（不收敛时的确定答案）

- 超迭代界 / 命中 R4②循环 ⇒ 回退到**保守近似**：相交判定回退为
  「AABB 重叠 + 中心距 ≤ 半径和」的**偏保守**答案（宁可误报相交，
  漏报才是穿模）；穿透深度回退为 AABB 最小轴重叠量。回退结果本身
  全为闭式运算 ⇒ 确定。回退触发率要求 = 测试池 **0**（见验收清单），
  触发即补退化用例进测试池而非放宽阈值。

### R6 数据入口（凸包顶点集）

- support 函数输入 = 定点化的顶点数组（`Vec<Vec3>`，加载期生成）。
  **确定性要点**：顶点序固定（加载序 = 文件序，不做运行时哈希迭代）；
  重复 / 共线顶点在**构建期**（`shape_from_hull` 一次性）用位比较
  去重（`PartialEq` 位语义 = `to_bits` 相等，NaN 视同相等折叠），
  运行期不再清洗——把非确定面压到烘焙期。

## 三、拆段裁决建议（本专章的结论）

| 段 | 内容 | 确定性风险 | 建议 |
|---|---|---|---|
| **P1：OBB 三形状对**（Box×Box、Box×Sphere、Box×Capsule） | **SAT 闭式 15 轴**（6 面法线 + 9 叉积轴），无迭代、无 GJK；叉积轴平行退化按现成 `any_orthonormal` 口径枚举处理；深度取最浅分离轴（并列取固定轴序 = 边界归属指定） | 低（全闭式 + 有限退化枚举） | **过审即开工**——直接根治 §8.27③ 埋臂（OBB 躯干）与旋转盒刚需 |
| **P2：OBB×{Sphere,Capsule} 混合已在 P1**；**任意凸包（GJK+EPA）** | support 函数式检测 + 穿透深度 | 中（R1–R5 全部适用，缓解手段均在本工程边界内，但测试池要对抗性构造） | **缓行**：等出现凸包真实消费方（武器命中体 / 载具）再单独立轮；届时本章程 R1 看门、R3–R5 条款直接生效 |

> 换言之：**「OBB + 凸包」池项按本章程一分为二**——OBB 走 SAT 闭式
> 路线（不依赖 GJK，「GJK 确定性最重」的池项理由实际只约束凸包半项），
> 凸包 GJK 按章程条款缓行。若用户裁定不接受拆分（OBB 必须与凸包同轮），
> 则整项按「未过审」处理，维持缓行。

## 四、验收清单（P1 排码时的硬门）

1. **算子看门单测**：SAT/GJK 内核源码 regex 断言无超越函数（R1 手段
   条）；
2. **确定性回归池**：≥ 200 组固定种子构型（splitmix64 计数流生成，
   禁 rand）——盒对盒随机姿态 × 随机半长 × 随机间距，每例两跑
   `to_bits` 全等；命中 / 分离 / 相切三态各占配额；
3. **边界归属断言**：恰相切（距离 = 半径和的 f32 可表达构型）判
   「不接触」（`penetration > SWEEP_CONTACT_EPSILON` 现行口径延伸），
   并列分离轴取轴序首位——逐条写死在单测；
4. **零变化锁**：未挂新形状的全部既有物理测试与六游戏快照逐位不变
   （新增形状 = 新枚举变体 ⇒ 旧路径 `match` 分支不动）；
5. **回退触发率 0** 进入②的池断言。

## 五、维持现状 / 拒绝清单

- 不做基于 GJK 的连续碰撞（`Ccd` 子步法已交付且确定性更廉价）；
- 不做 EPA 之上的软接触 / 摩擦锥扩展（v2 求解器口径）；
- 不做 MPR / Sutherland–Hodgman 穿透深度备选（EPA 足够，备选只增
  实现面）；
- wasm32：全部为 CPU 闭式运算，无 GPU 参与 ⇒ 跨 target 位级由 R1/R2
  条款覆盖，无额外声明。
